# Additional Documentation Assets

This directory contains additional documentation assets including database scripts, images, and backup files.

## Structure

```
docs/
├── database/          # Database scripts and SQL files
├── assets/            # Documentation images and assets
│   └── images/       # Screenshots and visual documentation
└── backup/           # Backup files (old versions)
```

## Contents

### Database (`database/`)
- SQL scripts for database operations
- Migration scripts
- Utility scripts

### Assets (`assets/images/`)
- Screenshots and visual documentation
- Debug images
- Interface analysis images

### Backup (`backup/`)
- Backup files from development
- Old versions of files
- Files kept for reference
