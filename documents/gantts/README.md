# Gantt Chart Files

This directory contains all Gantt chart related files for project planning and task tracking.

## Files

### Main Gantt Chart Files
- `GANTT_CHART_PROGRESS.md` - Project progress tracking with commit history
- `GANTT_CHART_TASKS.md` - Detailed task breakdown with descriptions
- `gantt_tasks.csv` - Main Gantt chart tasks in CSV format
- `gantt_restyled.csv` - Restyled Gantt chart with additional columns

### Weekly Task Files
- `week_01_oct_02_08_2025.csv` - Week 1 tasks (Oct 2-8, 2025)
- `week_01_october_2025.csv` - October 2025 tasks
- `week_02_oct_09_15_2025.csv` - Week 2 tasks (Oct 9-15, 2025)
- `week_02_november_01_08_2025.csv` - Week 2 tasks (Nov 1-8, 2025)
- `week_03_oct_16_22_2025.csv` - Week 3 tasks (Oct 16-22, 2025)
- `week_04_oct_23_29_2025.csv` - Week 4 tasks (Oct 23-29, 2025)
- `week_05_oct_30_nov_05_2025.csv` - Week 5 tasks (Oct 30 - Nov 5, 2025)
- `week_06_nov_06_12_2025.csv` - Week 6 tasks (Nov 6-12, 2025)
- `week_07_nov_13_19_2025.csv` - Week 7 tasks (Nov 13-19, 2025)
- `week_1_and_2_combined_tasks.csv` - Combined Week 1 and Week 2 tasks

## CSV Format

All CSV files follow a consistent format with the following columns:
- WBS # - Work Breakdown Structure number
- Group Name - Task category or group
- Task Name - Task description
- Start Date - Task start date (YYYY-MM-DD)
- End Date - Task end date (YYYY-MM-DD)
- Estimated Hours - Estimated hours for the task
- % Complete - Completion percentage (0-100)
- Notes - Additional notes and descriptions
- Comments - Comments field
- Task Color - Color coding (Green/Orange/Red)

## Usage

These files can be imported into Gantt chart tools like:
- ConfluPlan
- Microsoft Project
- GanttProject
- Other project management tools that support CSV import
