# Setup and Configuration Guides

This directory contains setup and configuration guides for various components of the BakeSync ERP system.

## Available Guides

- **SUPABASE_SETUP.md** - Supabase backend setup and configuration
- **SUPABASE_SETUP_INSTRUCTIONS.md** - Detailed Supabase setup instructions
- **EMAIL_VERIFICATION_SETUP.md** - Email verification system setup
- **SIGNUP_ONBOARDING_SETUP.md** - User signup and onboarding setup
- **PLAYWRIGHT_SETUP.md** - Playwright testing framework setup
- **PLAYWRIGHT_TESTING_GUIDE.md** - Comprehensive Playwright testing guide

## Quick Start

1. Start with [SUPABASE_SETUP.md](SUPABASE_SETUP.md) for backend configuration
2. Follow [EMAIL_VERIFICATION_SETUP.md](EMAIL_VERIFICATION_SETUP.md) for email verification
3. Review [PLAYWRIGHT_SETUP.md](PLAYWRIGHT_SETUP.md) for testing setup
